# projet-cloud-devops

Projet fil rouge de formation en cloud computing et DevOps, avec une orientation sécurité.

## Objectif
Construire pas à pas un petit projet complet : scripts Linux, application web, conteneurs Docker, déploiement automatique (CI/CD), infrastructure en code (Terraform) et Kubernetes.

## Structure du projet
- `scripts/` : scripts d'automatisation (Bash, Python)
- `docs/` : documentation
- `notes/` : notes d'apprentissage

## Avancement
- [x] Installation de Linux (Ubuntu sous WSL)
- [ ] Bases de Linux : navigation, fichiers, permissions
- [ ] Bash et Python pour l'automatisation
- [ ] Fondamentaux du cloud
- [ ] Docker et CI/CD
- [ ] Terraform
- [ ] Kubernetes et supervision
